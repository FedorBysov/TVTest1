# TVTest1

Рабочая папка будущего desktop-прототипа учебного тренажёра БЩУ. Сейчас в ней находятся исходное ТЗ, два варианта промпта и локальная копия навыка Anatomy. Сам прототип ещё не реализован.

## С чего начать

1. Откройте эту папку как отдельный проект.
2. Используйте [подробный актуальный промпт](anatomy_bshu_prompt_visual_v2.md). Вариант [первой редакции](anatomy_bshu_prompt.md) сохранён для сравнения.
3. При работе в Codex вызов навыка — `$anatomy`. В Claude Code — `/anatomy`; если навык не появился в открытой сессии, выполните `/reload-skills`.

## Состав

- `anatomy_bshu_prompt_visual_v2.md` — актуальный подробный промпт: только desktop, без VR на этом этапе, допускается многостраничный сайт.
- `anatomy_bshu_prompt.md` — предыдущая редакция промпта.
- `docs/original_specification.txt` — исходное ТЗ в том виде, в каком оно было предоставлено.
- `.agents/skills/anatomy/` — локальная копия Anatomy для Codex и совместимых агентов.
- `.claude/skills/anatomy/` — локальная копия Anatomy для Claude Code.

Обе копии Anatomy взяты из установленного навыка [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy). Они лежат внутри проекта, поэтому перенос проекта не затрагивает `engine` и не зависит от глобальной установки навыка. Авторские права и условия MIT находятся в `LICENSE` внутри каждой копии.

Для работы с примерами Anatomy нужен Node.js 20.10+ и Chrome/Chromium. Для статического SVG и примеров без фреймворка `npm install` не требуется. Зависимости отдельного проекта `engine` сюда не переносились, поскольку эти промпты их не используют.
