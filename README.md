# TVTest1 — учебный БЩУ ВВЭР / СМР

Интерактивный desktop-прототип: изометрический 3D-обзор щита, детальный SVG-модуль Anatomy, пять этапов, штатный маршрут и два учебных отклонения. Русский интерфейс со светлой и тёмной темами.

**Учебный прототип · условные данные · не для управления АЭС.** Это собирательный макет, а не модель конкретной станции, аттестованный тренажёр или готовый программно-аппаратный комплекс.

## Локальный запуск

Нужны Node.js 22.12+ и npm. Python требуется только для повторной генерации CAD: готовые STL уже в репозитории.

```sh
npm ci
npm run dev
```

Откройте [локальный сайт](http://127.0.0.1:5173/TVTest1/). При занятом порте Vite покажет другой адрес. Целевая среда — desktop-браузер с мышью и клавиатурой, окно от 1280×800; основной размер 1440×900. Для 3D нужен WebGL. При его отсутствии остаются HTML-кнопки выбора зон, показатели и учебные действия.

```sh
node scripts/verify-structure.mjs
npm test
npm run build
node scripts/verify-structure.mjs --dist
npm run preview
```

Сборка находится в `dist/`; preview по умолчанию доступен по адресу [127.0.0.1:4173/TVTest1/](http://127.0.0.1:4173/TVTest1/). Открывайте HTML через HTTP-сервер, не через `file://`. Verifier проверяет структуру, базовый путь, матрицу и контрольные суммы CAD; он не заменяет тесты поведения и проверку интерфейса в браузере.

## Страницы и демонстрация

Hash-маршруты не требуют серверных перенаправлений:

| Адрес после `/TVTest1/` | Содержание |
|---|---|
| `#/overview` | Обзор трёх зон, расширенный 3D-стол, показатели и переход к прибору |
| `#/console` | SVG-модуль, рукоятка, квитирование и устранение причины |
| `#/scenarios` | Пять этапов, маршруты, время, пауза, подсказки, график |
| `#/session` | Индивидуальный/групповой формат, роли, журнал и снимки |
| `#/help` | Инструкция, сигналы и ограничения |

Неизвестный маршрут открывает обзор. Занятие, зона и тема хранятся в `localStorage` браузера. Переходы сохраняют состояние, перезагрузка восстанавливает занятие; время закрытой вкладки не пересчитывается. При недоступном хранилище приложение работает в памяти. Смена профиля или сброс начинает новое занятие и очищает журнал; тема сохраняется.

На обзоре нажмите **«Развернуть стол»**: поверх страницы откроется увеличенная 3D-сцена в модальном окне. Щелчок по рукоятке повышает учебную команду на 25, `Shift` + щелчок понижает на 25; пределы — 0–100. Пять тумблеров выбирают этап, кнопка квитирования подтверждает активный сигнал. Выбор секции подсвечивает зону внутри расширенного вида. Под сценой есть обычные HTML-кнопки зон, этапов, значений команды и квитирования для клавиатуры. «Открыть прибор выбранной зоны» переводит на страницу пульта; «Свернуть» или `Esc` закрывает окно. Действия используют то же состояние и журнал, что остальные страницы. Устранение причины остаётся отдельным действием на пульте; управление временем находится на странице сценариев.

Для штатного маршрута выберите ВВЭР, откройте сценарии, запустите учебное время и последовательно выберите пять этапов. Измените рукоятку на пульте, сравните показатели с обзором. В разборе выберите событие: его снимок показывает прошлое, не меняя текущее состояние.

Для отклонений выберите СМР, маршрут снижения расхода либо расхождения индикаторов и введите отклонение. Получите подсказку, откройте пульт, квитируйте сигнал и отдельно устраните причину. Квитирование фиксирует подтверждение, но сохраняет активную причину. Повторите второй маршрут и сравните журнал.

Для группы на странице занятия выберите групповой формат. Инструктор может назначить текущий этап наблюдателю, оператору или инструктору. Переключите роль и выполните действия на других страницах: авторство попадёт в общий журнал. Это локальная имитация трёх участников в одном браузере.

## Модель и ограничения

Единый [редьюсер](src/sim/model.ts) формирует снимок для чисел, приборов, сигналов и журнала. Профили различаются компоновкой и вымышленными кривыми реакции. Мощность, температура, давление и расход нормированы в 0–100 условной шкалы; состояния систем образуют пятую категорию. Это не реальные физические единицы, уставки, расчёты или эксплуатационные инструкции.

Учебное время движется дискретными шагами; `+10 с` доступно при запущенном времени. Пауза останавливает динамику, оставляя ручной выбор и события отклонений доступными. График показывает недавние снимки условной мощности. Разбор считает посещённые этапы и подсказки, хранит цепочку событий; посещение этапа не означает освоение навыка. Профессиональная оценка правильности не реализована.

Нет сервера занятий, синхронизации участников, WebXR, связи с контроллерами и телеметрией АЭС. Данные занятия не отправляются наружу. Шрифты системные; код и CAD загружаются с того же сервера, что и сайт. Для автономной работы используйте локальный сервер: PWA и офлайн-кэш не реализованы. VR, три гарнитуры, совместимость, лицензии, гарантия и поставка — будущий комплекс, см. [матрицу покрытия](COVERAGE.md).

## CAD и ресурсы

Обзор построен Three.js из собственной геометрии и трёх оригинальных деталей build123d. Детальный прибор — SVG-код. Внешние изображения и модели конкретной станции не используются.

| Файл | Назначение |
|---|---|
| [cad/generate_parts.py](cad/generate_parts.py) | Параметрическая генерация и проверка повторяемости |
| [cad/parts-list.md](cad/parts-list.md) | Состав, опоры, оси, размеры и степени свободы |
| [bezel.stl](public/assets/cad/bezel.stl) | Рамка прибора с четырьмя отверстиями |
| [knob.stl](public/assets/cad/knob.stl) | Рифлёная рукоятка, вращение −126°…126° |
| [ack-button.stl](public/assets/cad/ack-button.stl) | Кнопка, ход −5…0 мм |
| [manifest.json](public/assets/cad/manifest.json) | Размеры, треугольники, SHA-256 геометрии, ограничения joints |

Для воспроизводимой генерации используйте Python 3.13 и build123d 0.13.0:

```sh
python3.13 -m venv .venv
.venv/bin/python -m pip install 'build123d==0.13.0'
.venv/bin/python cad/generate_parts.py
.venv/bin/python cad/generate_parts.py --check
```

Генерация обновляет `public/assets/cad/`. `--check` строит детали во временной папке внутри `cad/`, проверяет валидность и связность тел, сравнивает метаданные и геометрию с экспортами без их изменения. CAD задан в мм; масштаб сцены — 0.005 единицы/мм. Браузер воспроизводит движения через `AnimationMixer`. При ошибке загрузки STL остаётся процедурная замена. FreeCAD и соседний проект `engine` не требуются.
