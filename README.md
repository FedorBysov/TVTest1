# TVTest1 — учебный БЩУ ВВЭР / СМР

Интерактивный desktop-прототип: панорамный 3D-обзор, детальный SVG-модуль Anatomy, пять этапов с контрольными действиями, штатный маршрут, два учебных отклонения, разбор журнала и локальная группа вкладок. Русский интерфейс со светлой и тёмной темами.

**Учебный прототип · условные данные · не для управления АЭС.** Это собирательный макет, а не модель конкретной станции, аттестованный тренажёр или готовый программно-аппаратный комплекс.

## Локальный запуск

Нужны Node.js 22.12+ и npm. Python требуется только для повторной генерации CAD: готовые STL уже в репозитории.

```sh
npm ci
npm run dev
```

Откройте [локальный сайт](http://127.0.0.1:5173/TVTest1/). При занятом порте Vite покажет другой адрес. Целевая среда — desktop-браузер с мышью и клавиатурой, окно от 1280×800; основной размер 1440×900. Для 3D нужен WebGL. При его отсутствии остаются HTML-кнопки выбора зон, показатели и учебные действия.

```sh
node scripts/verify-structure.mjs
npm test
npm run build
node scripts/verify-structure.mjs --dist
npm run preview
```

Сборка находится в `dist/`; preview по умолчанию доступен по адресу [127.0.0.1:4173/TVTest1/](http://127.0.0.1:4173/TVTest1/). Открывайте HTML через HTTP-сервер, не через `file://`. Verifier проверяет структуру, базовый путь, матрицу и контрольные суммы CAD; он не заменяет тесты поведения и проверку интерфейса в браузере.

## Страницы и демонстрация

Hash-маршруты не требуют серверных перенаправлений:

| Адрес после `/TVTest1/` | Содержание |
|---|---|
| `#/overview` | Разные компоновки ВВЭР и СМР, три зоны, расширенный 3D-пост, показатели |
| `#/console` | Зональный SVG-модуль, наблюдение, рукоятка, квитирование и устранение причины |
| `#/scenarios` | Пять этапов, чеклисты, следующий шаг, отклонения, время и график |
| `#/session` | Группа вкладок, роли, журнал, оценка порядка, снимки и экспорт JSON |
| `#/help` | Инструкция, сигналы и ограничения |

Неизвестный маршрут открывает обзор. Индивидуальное занятие хранится в `sessionStorage` отдельно для каждой вкладки; зона и тема — в `localStorage`. Перезагрузка той же вкладки восстанавливает её занятие; закрытие вкладки завершает его, поэтому для длительного хранения скачайте JSON-разбор. Старое сохранение v1/v2 из `localStorage` импортируется при первом открытии новой версии. Время закрытой вкладки не пересчитывается. Групповая связь действует, пока открыты участвующие вкладки, и после перезагрузки создаётся или подключается заново. При недоступном хранилище индивидуальное занятие работает в памяти. Смена профиля или сброс начинает новое занятие и очищает журнал; тема сохраняется.

Профиль ВВЭР показывает длинную гибридную приборную стену с разными секциями и рабочими местами; профиль СМР — более компактный экранный пост. Это самостоятельные собирательные композиции по открытым референсам, без точной планировки конкретной АЭС. На обзоре нажмите **«Развернуть стол»**: в большом виде можно выбрать фокус зоны, изменить масштаб кнопками или колесом и сдвинуть изображение перетаскиванием. Щелчок по рукоятке повышает учебную команду на 25, `Shift` + щелчок понижает на 25; пределы — 0–100. Пять тумблеров выбирают этап, кнопка квитирования подтверждает активный сигнал. Кликабельны основные секции и настенная панель. Под сценой есть обычные HTML-кнопки зон, этапов, значений команды и квитирования для клавиатуры. «Открыть прибор выбранной зоны» переводит на страницу пульта; «Свернуть» или `Esc` закрывает окно. Устранение причины остаётся отдельным действием на пульте; управление временем находится на странице сценариев.

Для штатного маршрута выберите ВВЭР, откройте сценарии и пройдите контрольные действия пяти этапов. На пульте запишите наблюдения нужных зон, измените учебную команду и запустите время для отклика условных приборов. Свободный выбор этапа разрешён; пропуски и нарушения порядка затем отмечаются в разборе. Выбор события в журнале показывает прошлый снимок, не меняя текущее состояние.

Для отклонений выберите СМР, маршрут снижения расхода либо расхождения индикаторов и введите отклонение. На странице сценария и соответствующей зоне пульта сопоставьте показание с **условным ориентиром** той же модели без отклонения и разницей; это не уставка оборудования. Запишите наблюдение, квитируйте сигнал, отдельно устраните причину и проверьте состояние повторным наблюдением. Квитирование фиксирует подтверждение, но сохраняет активную причину. Чеклист показывает следующий шаг, а разбор объясняет пропущенные или выполненные вне порядка действия.

Для группы откройте сайт в двух или трёх вкладках одного браузерного профиля и адреса сайта. В первой вкладке создайте занятие: она становится **инструктором** и показывает код. В остальных вкладках введите код и выберите роль **оператора** или **наблюдателя**. Инструктор управляет маршрутом, временем и назначением этапа; оператор использует разрешённые органы управления; наблюдатель записывает наблюдения. Ведущая вкладка применяет действия к общей модели и рассылает снимки через `BroadcastChannel`. Если ведущая вкладка закрыта или связь потеряна, действия участников блокируются до восстановления связи. Это синхронизация вкладок одного origin, без сервера для разных компьютеров; код занятия не является средством аутентификации.

## Модель и ограничения

Единый [редьюсер](src/sim/model.ts) формирует снимок для чисел, приборов, сигналов и журнала. Профили различаются компоновкой и вымышленными кривыми реакции. Мощность, температура, давление и расход нормированы в 0–100 условной шкалы; именованные состояния систем образуют пятую категорию. Это не реальные физические единицы, уставки, расчёты или эксплуатационные инструкции. Наблюдение зоны сохраняет показания и этап в журнале.

Учебное время движется дискретными шагами; `+10 с` доступно при запущенном времени. Пауза останавливает динамику, оставляя ручной выбор и события отклонений доступными. График показывает недавние снимки условной мощности. [Оценщик](src/sim/assessment.ts) использует компактно сохранённые доказательства шагов из журнала и отмечает контрольные действия пяти этапов и двух отклонений как выполненные по порядку, выполненные вне порядка или пропущенные. Полный журнал ограничен 500 событиями, поэтому для длительного архивирования скачайте JSON до вытеснения ранних записей. Это демонстрационная проверка взаимодействия с прототипом, не оценка квалификации персонала. Отчёт и текущий журнал можно скачать в JSON.

Синхронизация группы работает через `BroadcastChannel` между вкладками одного origin и не передаёт занятие между разными устройствами или браузерными профилями. Нет сервера занятий, WebXR, связи с контроллерами и телеметрией АЭС. Файл отчёта создаётся в браузере; занятия не отправляются на сервер приложения. Шрифты системные; код и CAD загружаются с того же сервера, что и сайт. Для автономной работы используйте локальный сервер: PWA и офлайн-кэш не реализованы. VR исключён из текущего объёма по решению пользователя; лицензия продукта, гарантия, инструктаж у заказчика и физическая поставка не подтверждены веб-прототипом — см. [матрицу покрытия](COVERAGE.md).

## CAD и ресурсы

Обзор построен Three.js из собственной геометрии и трёх оригинальных деталей build123d. Детальный прибор — SVG-код. Внешние изображения и модели конкретной станции не используются.

| Файл | Назначение |
|---|---|
| [cad/generate_parts.py](cad/generate_parts.py) | Параметрическая генерация и проверка повторяемости |
| [cad/parts-list.md](cad/parts-list.md) | Состав, опоры, оси, размеры и степени свободы |
| [bezel.stl](public/assets/cad/bezel.stl) | Рамка прибора с четырьмя отверстиями |
| [knob.stl](public/assets/cad/knob.stl) | Рифлёная рукоятка, вращение −126°…126° |
| [ack-button.stl](public/assets/cad/ack-button.stl) | Кнопка, ход −5…0 мм |
| [manifest.json](public/assets/cad/manifest.json) | Размеры, треугольники, SHA-256 геометрии, ограничения joints |

Для воспроизводимой генерации используйте Python 3.13 и build123d 0.13.0:

```sh
python3.13 -m venv .venv
.venv/bin/python -m pip install 'build123d==0.13.0'
.venv/bin/python cad/generate_parts.py
.venv/bin/python cad/generate_parts.py --check
```

Генерация обновляет `public/assets/cad/`. `--check` строит детали во временной папке внутри `cad/`, проверяет валидность и связность тел, сравнивает метаданные и геометрию с экспортами без их изменения. CAD задан в мм; масштаб сцены — 0.005 единицы/мм. Браузер воспроизводит движения через `AnimationMixer`. При ошибке загрузки STL остаётся процедурная замена. FreeCAD и соседний проект `engine` не требуются.
