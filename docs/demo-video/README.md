# TVTest1 — короткая демонстрация

Формат: примерно одна минута, desktop 16:9, запись настоящего сайта, русская озвучка и субтитры. Цель — показать основные действия, а не имитировать эксплуатацию реального БЩУ.

## Сцены

1. Обзор собирательного 3D-поста ВВЭР и оговорка об условных данных.
2. Развёрнутый стол: масштаб, зона, нажатие на физический орган управления и изменение учебной команды.
3. Переключение на отдельную компоновку СМР.
4. Приборный модуль и пять учебных этапов.
5. Введение отклонения расхода, предупреждение и сравнение с условным ориентиром.
6. Журнал, снимок события и оценка порядка действий; финальная ссылка.

Исходные реплики находятся в `narration/`. `scripts/demo/capture.mjs` повторяет действия в браузере, а `scripts/demo/render.mjs` собирает ролик. Рабочие записи и аудио лежат в `.cache/demo/` и не публикуются.

Запись с публичного сайта предшествует обновлению страницы с видеоплеером, чтобы ролик показывал уже опубликованную интерактивную версию. Компоновка и показания вымышлены. В ролике нет кадров реальной АЭС.
