# Учебный БЩУ — проект веб-прототипа

Статус: рабочее проектное решение. Пользователь задал ТЗ, desktop, запрет VR, требование реалистичного вида и инструменты build123d, Three.js, Anatomy. Стек и компоновка ниже — решение реализации.

## Зачем и для кого

Создать русскоязычный сайт, на котором студент может осмотреть собирательный учебный щит, взаимодействовать с условными органами управления, пройти пять учебных этапов и два отклонения, затем получить разбор действий. Результат открывается локально и по ссылке после публикации из отдельного репозитория TVTest1.

## Источники и границы

- Исходное ТЗ: `docs/original_specification.txt`.
- Детализированное описание среза: `anatomy_bshu_prompt_visual_v2.md`.
- Новый запрос о build123d, Three.js и кинематике имеет приоритет над прежним предложением ограничиться SVG.
- Только desktop: 1280×800, 1440×900, 1920×1080. VR, WebXR и мобильная верстка вне этапа.
- Вымышленный учебный тренажёр: ни одно значение, действие или внешний вид не выдаётся за документацию действующей АЭС. Постоянная пометка: «Учебный прототип · условные данные · не для управления АЭС».

## Рассмотренные способы

1. Только SVG/HTML по Anatomy: легче, но не выполняет новое требование о Three.js и CAD-деталях.
2. Свободно перемещаемая 3D-комната: дороже в создании и проверке, усложняет учебный маршрут и доступность.
3. **Выбрано:** фиксированная 3D-карта трёхсекционного щита на главной странице, детальный изометрический SVG-модуль Anatomy на странице пульта, семантический HTML для сценариев, журнала и помощи. Кинематика деталей синхронизирована с единой моделью.

## Страницы

Пять разделов в одном статическом приложении с hash-маршрутами для GitHub Pages: `#/overview`, `#/console`, `#/scenarios`, `#/session`, `#/help`. Постоянная навигация показывает профиль, этап и сигнал. Переходы сохраняют модель; неверный hash ведёт на обзор.

1. **Обзор:** изометрическая 3D-карта поста. Три зоны выбираются сценой и соседними HTML-кнопками; справа пять условных показателей. Кнопка «Развернуть стол» открывает почти полноэкранный desktop-вид, где рукоятки, квитирование и пять переключателей этапов работают непосредственно на 3D-модели. Все действия продублированы HTML-кнопками.
2. **Пульт:** Anatomy Figure: прибор, рукоятка, защищённая кнопка квитирования, лампа. Рядом доступные HTML-органы управления и числовые дубли.
3. **Сценарии:** пять этапов, штатный маршрут и два отклонения, часы, пауза, продолжение, сброс, подсказка, график.
4. **Занятие и разбор:** индивидуальный и локально имитируемый групповой режим, три роли, назначение шага, журнал со снимками и причинная хронология.
5. **Помощь:** правила взаимодействия и границы демонстрации.

## Единая модель

`src/sim/model.ts` — чистый reducer и селекторы без DOM, Three.js и React. Состояние хранит профиль (`vver`/`smr`), этап (0–4), сценарий (`normal`/`flow`/`split`), условное время, паузу, положение рукоятки, причину отклонения, квитирование, подсказки, режим занятия, роли и журнал. `deriveSnapshot(state)` выводит мощность, температуру, давление, расход, состояние систем и сигнала по условной шкале 0–100. События журнала сохраняют неизменяемый снимок на момент действия. Для долгого занятия снимки часов записываются раз в 10 секунд, история ограничена 500 событиями, а сохраняемые данные проверяются по полной структуре снимка. Смена профиля начинает новое занятие и не сбрасывает тему. Квитирование не устраняет причину. Пауза останавливает модельное время и динамику показаний. Одинаковые действия дают одинаковый результат.

## Физика изображения и анимация

`cad/generate_parts.py` создаёт оригинальные учебные детали с build123d: обод прибора, рукоятку, кнопку квитирования. Скрипт и низкополигональные STL хранятся в TVTest1. Он не меняет `engine`; у проекта собственная `.venv`. Детали имеют понятные оси и ход. Three.js показывает раму, наклонную консоль, приборы, лампы, крепёж, кресло и CAD-детали. `AnimationMixer` проигрывает поворот, нажатие и движение стрелки; конечные позы берутся из снимка модели. Цифровые табло закреплены над пересечением с наклонным столом и читаются полностью в обоих профилях. Камера фиксирована, в расширенном виде вмещает весь щит и кресло. При недоступном WebGL остаются HTML-кнопки и показания.

Anatomy Figure показывает тот же физический модуль с корпусом, креплениями, шкалой, лампой и движущимися деталями. Он строится из локальной копии Anatomy. Figure и 3D получают одинаковый снимок модели.

## Визуальное направление

Оригинальный собирательный пульт. Тезис: «Техническая точность чувствуется как материальный предмет: спокойная геометрия окрашенного металла делает заметными лишь движения и сигналы, которые объясняют состояние занятия».

- Матовый графитовый металл, утопленные рамки, резиновые рукоятки и защищённые лампы; стыки и опоры вместо плавающих карточек.
- Светлая тема: тёплый серый фон; тёмная: глубокий графит. Один холодный акцент выбора, янтарный треугольник предупреждения, красный восьмиугольник тревоги.
- Длинные русские подписи и числовые дубли — в HTML. Табличные цифры. Состояния различаются знаком и текстом, не одним цветом.
- Фиксированная изометрическая камера, мягкий верхний и боковой свет; без бликов, скрывающих шкалы.
- Движение только причинное: рукоятка при команде, стрелка при показании, кнопка при квитировании. `prefers-reduced-motion` даёт конечную позу без перехода.

Отдельный пакет правил и токенов: `docs/visual-direction.md` и `src/styles/tokens.css`.

## Технологии и публикация

Vite + React + TypeScript + Three.js, локальная копия Anatomy, build123d как инструмент подготовки деталей. Данные и ресурсы локальные; внешнего телеметрического API нет. `npm run build` создаёт `dist/`. GitHub Actions собирает и публикует `dist/` в GitHub Pages при push в `main`, база `/TVTest1/`. Пользователь выбрал публичный репозиторий; в настройках Pages выбран источник GitHub Actions.

## Приёмка

Автоматически: тесты детерминизма, сброса, квитирования, паузы, журнала и профилей; TypeScript/Vite build; CAD-экспорт; smoke-проверка маршрутов. В браузере: штатный и два отклонения, мышь и клавиатура, три desktop-размера, две темы, reduced motion, отсутствие ошибок консоли. Визуально: прибор на 1× и 4×, читаемые зоны, материальные соединения, разный силуэт профилей. Матрица исходного ТЗ — `COVERAGE.md`.
