# Реестр поставки и внешних обязательств

Этот реестр не является актом приёмки и не изменяет исходное ТЗ. Он отделяет файлы веб-прототипа от обязательств поставщика по готовому программно-аппаратному комплексу. VR-пункты исключены из текущей разработки по решению пользователя.

| Пункт исходного ТЗ | Что есть в TVTest1 | Что ещё требуется для подтверждения исполнения |
| --- | --- | --- |
| 1 комплект ПО | Публичный репозиторий с исходниками, собираемый desktop-сайт на GitHub Pages, CAD-источники и ресурсы | Утверждённая версия продукта, комплект поставки, носитель/способ передачи, испытания и подписанная приёмка заказчиком |
| Лицензия ПО | Лицензии сторонних библиотек и навыка сохранены в проекте | Решение правообладателя об условиях лицензии **самого TVTest1**, числе пользователей, сроке и области использования; документ поставки. Публичный GitHub-репозиторий не устанавливает эти условия |
| Руководство и техническая документация | `docs/user-guide.md`, `docs/technical-description.md`, `docs/demo-runbook.md`, `docs/references.md`, `COVERAGE.md`, README | Согласование комплекта с заказчиком и документация полного комплекса/оборудования при фактической поставке |
| Инструктаж, 1 услуга | Сценарий показа подготовлен | Фактическое занятие с заказчиком, список присутствующих, дата и подтверждение проведения |
| Установка, настройка и проверка | Сайт опубликован; команды локального запуска и автоматические проверки описаны | Установка в среде заказчика, проверка на его оборудовании/сети, протокол результатов и приёмка |
| Демонстрация учебных сценариев | Штатный маршрут и два учебных отклонения доступны на сайте; сценарий показа описан | Проведённая демонстрация заказчику и согласованный протокол, если это условие договора |
| Гарантия и техническая поддержка | GitHub Issues может использоваться для сообщения об ошибках, но не создаёт договорных прав | Подписанный договор с составом услуг, сроками реакции, сроком гарантии и ответственными лицами |
| Доставка за 45 дней, комплектность и упаковка | Статический сайт доступен по ссылке | Договор, дата отсчёта срока, адрес, физическая комплектация, упаковка, доставка/погрузка/разгрузка и подтверждающие документы |

**На дату создания реестра ни одно из перечисленных внешних договорных обязательств не подтверждено как исполненное.** Открытый исходный код и успешный GitHub Actions являются техническими свидетельствами веб-прототипа, а не доказательством поставки полного комплекса.
